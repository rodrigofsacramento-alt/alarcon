# UI Design System
Professional toolkit for creating and maintaining scalable design systems.
## Core Capabilities
- Design token generation (colors, typography, spacing)
- Component system architecture
- Responsive design calculations
- Developer handoff tools
## When to Use This Skill
- Creating design systems from scratch
- Maintaining visual consistency across multiple landing pages
- Creating clean, consistent spacing and typography scales
- Facilitating design-dev handoff
## Spacing and Typography System
### Spacing Grid (8pt Grid)
Use the 8pt spacing grid to align components, margins, and paddings:
- **xs**: 4px (0.25rem)
- **sm**: 8px (0.5rem)
- **md**: 16px (1.0rem)
- **lg**: 24px (1.5rem)
- **xl**: 32px (2.0rem)
- **xxl**: 48px (3.0rem)
- **xxxl**: 64px (4.0rem)
### Typography Scale
Use these standard typographic roles and sizes:
- **Display 1 (Hero)**: 72px / 4.5rem, line-height: 1.1, font-weight: 800 (Playfair Display / Serif)
- **Display 2 (Section Title)**: 48px / 3.0rem, line-height: 1.2, font-weight: 700 (Playfair Display / Serif)
- **Heading 1**: 32px / 2.0rem, line-height: 1.3, font-weight: 600 (Inter / Sans-serif)
- **Heading 2**: 24px / 1.5rem, line-height: 1.4, font-weight: 600 (Inter / Sans-serif)
- **Heading 3**: 20px / 1.25rem, line-height: 1.4, font-weight: 600 (Inter / Sans-serif)
- **Body Lead**: 20px / 1.25rem, line-height: 1.6, font-weight: 300 (Inter / Sans-serif)
- **Body Main**: 16px / 1.0rem, line-height: 1.6, font-weight: 400 (Inter / Sans-serif)
- **Body Small**: 14px / 0.875rem, line-height: 1.6, font-weight: 400 (Inter / Sans-serif)
- **Caption / Label**: 12px / 0.75rem, line-height: 1.5, font-weight: 500, letter-spacing: 1.5px (Inter / Sans-serif)
